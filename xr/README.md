# XRbox Godot project

Godot scenes, shared controller UI, OpenXR input and Android platform glue live here.
The native bridge is in `crates/xrbox-godot`; streaming/session ownership stays in
`crates/xrbox-core`. Host previews remain synthetic.

See the [XR development guide](../docs/xr-development.md),
[Android build and test guide](../docs/android.md),
[Frame test plan](../docs/frame-test-plan.md) and
[documentation index](../docs/README.md).
