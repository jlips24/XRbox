# XRbox v0.0.1 — Quest 3S test build

First experimental Android ARM64 test release for Xbox console Remote Play.
The APK displays **0.0.1** (version code 11003). Internal Rust core: 0.1.10.

- Native Microsoft device-code sign-in, console discovery, streaming, audio and
  controller pipeline; no relay PC or embedded browser runtime.
- Controller-first menus with fixed version footer, screen controls and diagnostics.
- Meta Touch menus: either stick navigates, A/X selects, B/Y goes back, stick
  click opens/closes the local menu. A Bluetooth Xbox controller is required for
  console gameplay. Physical system/Guide buttons remain reserved to the host.
- Remembered refresh credentials use secure platform storage; session-only sign-in
  is available. Full settings/custom hotkey editing and hand tracking are not included.

Local APK signature/ABI/alignment/manifest checks and synthetic headless tests
passed. Actual Quest 3S sign-in, Keystore restoration, moving video, audible audio,
physical controls and XR lifecycle still require device acceptance. No latency,
zero-copy or battery claims are made.

The Linux ARM64 attachment is a native extension only, not a complete Frame app.
Linux live decoding/import and Flatpak support remain unfinished.

See [installation and Quest testing](https://github.com/jlips24/XRbox/blob/v0.0.1/docs/android.md#install-and-test). These APKs
are development-signed. Verify the attached artifact's checksum/build metadata;
CI and local development keys can differ, affecting in-place updates.
